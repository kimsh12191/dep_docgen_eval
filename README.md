# docgen_eval (template-html) — 문서 이미지 → 수정 가능한 HTML 템플릿

## 왜
업무 중 들어오는 문서(은행 서식, 기관·정부 문서, 스캔·사진)를 사람이 라벨링해 KIE·문서분류 모델을 만드는 수고를 줄인다.
문서 이미지 한 장을 **수정 가능한 템플릿**으로 바꿔 두면, 값과 표 행을 바꿔 가며 **라벨이 붙은 문서 이미지를 자동으로 대량 생성**할 수 있다.

## 누가 무엇을
| 누가 | 넣는 것 | 받는 것 |
|---|---|---|
| 사용자 | 문서 이미지 1장 | **템플릿 꾸러미** (아래) |
| 외주·다른 사람 | 꾸러미 + 값(json). 값은 파이썬이나 LLM 으로 만든다 | 문서 이미지 N장 + 라벨(어느 위치에 무슨 값) |

## 템플릿 꾸러미
```
<꾸러미>/
  template.html   문서의 틀 (Jinja2). 값은 {{ 이름 }}, 반복되는 표 행은 {% for %}. 값마다 data-field 로 위치를 알 수 있게 감싼다
  schema.json     들어가는 값의 목록: 항목(fields) · 반복 표(tables) · 종류
  sample.json     원본 이미지의 내용대로 채운 예시 값
```
규칙은 [`tplgen/prompts/template_v1.md`](tplgen/prompts/template_v1.md) 가 전부다 (모델에 주는 지시문이 곧 규격).
표 행은 값 목록의 길이만큼 늘고, 아래 내용은 저절로 밀린다 — 그래서 SVG 가 아니라 HTML 이다.

## 쓰는 법
```bash
# 1) 이미지 → 꾸러미 (모델 + 셀프 고치기 루프). 설정은 configs/example.json 을 복사해 고친다
python -m tplgen make --config configs/local.json --name model_a --image samples/hf153.png --out out/hf153

# 2) 꾸러미 + 값 → 이미지 + 라벨
python -m tplgen render out/hf153/final --data my.json --out gen/0001        # 0001.png, 0001.json
python -m tplgen vary   out/hf153/final --n 20 --out gen/                    # 값을 임의로 바꿔 20장

# 3) 꾸러미가 쓸 만한가 (정답 없이 잰다)
python -m tplgen check out/hf153/final --image samples/hf153.png

# 4) 여러 모델 × 여러 이미지 비교
python -m tplgen bench configs/local.json
```

## 잘 만들었는지 재는 법 (`check`)
정답 파일 없이, **꾸러미를 실제로 돌려 보고** 잰다.

| 점수 | 뜻 |
|---|---|
| 유효 `valid` | 규칙대로이고 예시 값으로 그려지는가 |
| 닮음 `layout` | 예시 값으로 그린 그림과 원본이 위에서 아래로 같은 모양의 줄을 같은 순서로 갖는 정도 (0~1). 글꼴·행 높이·여백 차이는 봐주고, 사진은 종이 부분만 잘라 비교하며, 그림 자리(바코드 등)는 채워진 것으로 본다 |
| 견딤 `robust` | 값을 바꾸고(짧게·길게) 표 행을 바꿔(0·1·많이) 그려도 깨지지 않는 비율. 깨짐 = 넘침·겹침·값 누락·행 수 불일치 |
| 샘 `leak` | 예시 값이 틀에 고정 글자로 박혀 있는 수 (0 이어야 함) |
| 자리 수 | 항목·표·표의 열 개수 (참고) |

**쓸 만함(임시 기준) = 유효 ∧ 견딤 = 1 ∧ 샘 = 0 ∧ 닮음 ≥ 0.6.** `tplgen/check.py` 의 `PASS_RULE`.

## 지금 상태
본보기 꾸러미 셋은 모두 **큰 모델 하나가 이미지를 보고 쓴 것**이다 (사람이 쓴 것도, vLLM 모델이 쓴 것도 아니다).

| 본보기 | 입력 | 닮음 (회차별) | 견딤 | 본 것 |
|---|---|---|---|---|
| [`hf153`](examples/hf153) | 깨끗한 은행 서식 (표 5행) | 0.63 → 0.86 (스캔본과는 0.76) | 1.0 | 표 행 1·5·20·40 으로 그려도 아래 내용이 밀리며 안 깨짐 |
| [`receipt_photo`](examples/receipt_photo) | 찍은 영수증 사진 | 0.77 | 1.0 | 배경을 빼고 종이만 옮김. 로고·바코드·QR 은 자리만 |
| [`statement`](examples/statement) | 합성 거래내역서 (표 29행) | 0.84 | 1.0 | 행 수 1~60 |
| [`irs_f8949`](examples/irs_f8949) | 미국 세금 서식, 여러 단 머리글 표 | 0.81 → 0.86 | 1.0 | 머리글 rowspan/colspan, 합계 행, 체크 A~I |
| [`irs_fw9`](examples/irs_fw9) | 빽빽한 미국 세금 서식 | 0.80 → 0.82 | 1.0 | 한 칸 한 글자 번호 칸(SSN·EIN), 두 단 본문 |
| [`invoice_photo_skewed`](examples/invoice_photo_skewed) | 심하게 비스듬히 찍은 인보이스 | 0.59 → 0.72 | 1.0 | 원근 보정이 없을 때는 맞는 꾸러미도 0.26 이었다 (아래) |
| [`invoice_handwritten`](examples/invoice_handwritten) | 손으로 채운 인쇄 장부 | 0.82 | 1.0 | 손글씨 값은 값으로 빼고, 손글씨처럼 꾸며 찍음 |

| | |
|---|---|
| 확인함 | 점수가 망가진 꾸러미를 잡는가 (`tests/`): 값이 틀에 박힘 → 샘, 표 폭 고정 → 넘침, 칸 높이 고정 → 잘림, 행이 안 늘어나는 표 → 값 누락, 본문 빠짐 → 닮음 하락 |
| 확인함 | 닮음 점수의 기준점 (hf153): 같은 문서 0.8 안팎 · 스캔본 0.76 · **전혀 다른 문서 0.4 안팎**. 처음 쓴 방식(잉크 위치를 그대로 겹침)은 다른 문서와도 0.6 이 나와 버렸다 |
| 확인함 | 루프: 고쳐서 나아지면 뒤 회차를, 고치다 망가지면 앞 회차를 final 로 고름 |
| 고친 것 (복잡한 문서 시험에서) | **평가**: 비스듬히 찍은 사진은 종이를 네모로만 자르면 배경과 기울기가 남아 맞는 꾸러미도 0.26 → 종이의 네 모서리를 찾아 펴서 비교 (0.59, 고친 뒤 0.72). 영수증 사진도 0.66 → 0.77 |
| 고친 것 | **값 만들기**: 영어 문서에 한국어 값이 들어감 → schema 의 `language`. 날짜·금액 꼴이 원본과 다름 → `format` (`DD/MM/YYYY`, `R # ###,##`, `###-##-####`) |
| **아직 안 함** | **실제 vLLM 모델로 돌리기** |
| **아직 안 함** | 닮음 점수가 사람 눈과 맞는지. 같은 문서/다른 문서는 가르지만 **작은 차이에는 둔하다** (영수증에서 줄 넘김을 고쳐도 0.66 그대로). 0.05 보다 작은 차이는 오차로 본다 |
| **아직 안 함** | 사람이 스캐너로 뜬 실제 스캔본, 여러 쪽 문서, 심하게 기운 사진 (기울면 닮음이 내려간다: 1.2° 에 0.86 → 0.76) |
| 모르는 것 | 사내에서 HTML 그리기 — Playwright Chromium 을 도커에 넣어 쓸 예정 |
| 재지 않는 것 | **값끼리 맞는가**: 합계가 품목 합과 다르고, 만기일이 발행일보다 앞설 수 있다. 칸의 뜻까지 맞는 값은 schema.json 을 LLM 에 주고 만들게 해야 한다 |
| 재지 않는 것 | 값이 아닌 글자끼리 겹침 · 쪽 나눔(행이 많으면 한 장이 길어진다) · 만든 이미지를 스캔·사진처럼 만드는 것(`tools/scanify.py` 가 시작점) |

## 폴더
| | |
|---|---|
| `tplgen/` | `make` 생성·루프 · `package` 꾸러미 읽기·검사 · `render` 그리기·라벨 · `data` 값 만들기 · `check` 점수 · `bench` 모델 비교 · `llm` · `config` |
| `examples/` | 본보기 꾸러미 |
| `samples/` | 입력 예시 이미지와 출처 ([목록](samples/README.md)) |
| `tools/` | `scanify.py` 깨끗한 그림을 스캔처럼 |
| `configs/` | 실행 설정 |

`main` 브랜치는 예전 방식(SVG 값 자리 평가)이다. **실서류 이미지는 사내 모델 주소에만 보낸다.**
