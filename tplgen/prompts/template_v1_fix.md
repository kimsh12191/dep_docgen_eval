할 일
- 그림을 원본과 비교한다. 빠진 문구·표·칸, 다른 순서·위치·크기·정렬, 줄이 어색하게 바뀐 곳(칸이 좁아 글자가 세로로 쪼개진 머리글 등)을 원본처럼 고친다.
- 원본에 적힌 값이 틀에 고정 글자로 남아 있으면 값으로 뺀다. 원본의 기재란인데 값이 아닌 곳이 있으면 값으로 만든다.
- 아래 시험에서 깨진 것을 고친다.
  - overflow_x: 쪽보다 넓어짐 → 폭을 %나 flex 로, 긴 값은 줄바꿈되게
  - clipped: 칸보다 내용이 큼 → 고정 height 대신 min-height, overflow 로 숨기지 않기
  - overlap / outside: 값끼리 겹치거나 쪽 밖 → 절대 위치를 흐름 배치로
  - missing: schema 에 있는 값이 그림에 없음 → template 에 data-field 로 넣기 (표는 행 반복문 안에)
  - 규칙 위반(아래 "규칙 검사")은 모두 고친다
- 고칠 것이 없으면 직전 파일을 그대로 다시 출력한다.
