# 공식 원본 기반 gold 후보 v1

2026-11-12: `ref.svg`와 `ref_svg.png`를 추가했습니다. 새 생성 실험은 `formgen svg`를 사용합니다.
원본 PDF/PNG와 기존 HTML은 출처·회귀 대조용으로 보존합니다. 변환해도 gold 승인 상태는 바뀌지 않습니다.

공식 사이트에서 2026-11-12 내려받은 PDF를 직접 래스터화한 입력과,
bank_benchmark/docgen/forms의 공식대조 HTML을 변환한 정답 **후보**입니다.
원본 PDF의 SHA-256을 기존 HTML 출처 기록과 대조하여 3종 모두 일치했습니다.
모델 생성 HTML을 입력 이미지로 다시 그린 roundtrip 데이터가 아닙니다.

| 잠정 난이도 | 항목 | 현재 주석 수 | 출처 |
|---|---|---:|---|
| 하 | 국민연금가입자 증명서 | 6 | [공식 PDF](https://www.law.go.kr/LSW/flDownload.do?gubun=&flSeq=161706061&bylClsCd=110202) |
| 중 | 사업자등록증명 | 10 | meta.json의 국가법령정보센터 URL |
| 상 | 소득금액증명 | 23 | meta.json의 국가법령정보센터 URL |

난이도는 페이지의 기재 구역·표 밀도·필드 수에 따른 잠정 분류이며 사람 판정/실험으로 보정해야 합니다.
세 문서는 정부 공식 빈 서식이며 실제 작성·스캔 문서가 아닙니다. 소득금액증명은 원본의 QR이 HTML에서 빠져 있습니다.
그대로 배포 가능한 라이선스인지 확인한 것은 아닙니다. 출처와 원문은 내부 연구 검토용으로 보존했습니다.

## 파일

- `source.pdf`: 다운로드한 원문 그대로. 최신 서식이라는 보장은 하지 않습니다.
- `image.png`: PDF 첫 페이지를 192 dpi로 래스터화한 모델 입력.
- `ref.html`, `ref.png`: 스크립트와 외부 폰트 의존성을 제거하고 글자 폭 보정을 인라인에 고정한 후보.
- `fields.json`: 상속받은 필드 정의 및 브라우저에서 측정한 좌표.
- `source_text.json`: PDF 텍스트와 좌표. 일부 제목은 윤곽선이어서 텍스트로 추출되지 않습니다.
- `comparison.png`: 왼쪽 공식 원문, 오른쪽 HTML 렌더링.
- `meta.json`: 출처·해시·난이도 이유·검토 상태. 모든 항목은 `gold_approved:false`입니다.

## 시각 검토에서 확인한 미해결 사항

- 국민연금가입자 증명서: 발급번호, 하단 발급 날짜, 직인 자리가 필드 목록에서 빠져 있습니다.
- 사업자등록증명: 공동사업자/하단 접수·담당자 구역 등 전체 빈칸의 주석 완전성을 다시 확인해야 합니다.
- 소득금액증명: 종합소득/연말정산의 모든 입력 칸과 선택 상태 주석, QR 제외 영역을 검토해야 합니다.
- SVG로 그린 글자는 DOM 텍스트 점수에 반영되지 않습니다. DOM 표가 없으므로 v1 table_f1은 유효한 지표가 아닙니다.
- 시각적 글자 두께와 세부 글꼴은 시스템 대체 폰트 때문에 차이가 있습니다.

이 상태를 완성된 gold로 보고하지 않습니다. 벤치마크 CLI는 기본적으로 실행을 거절하며,
개발용 실행에 한해 `--allow-candidates`를 명시할 수 있습니다.

## 승인 조건

1. 원본의 모든 기재 칸을 주석화하고, 고정 문구/문서별 가변값 범위를 명확히 정의.
2. 날짜 분할과 체크 묶음의 동등한 표현을 정의하고 필드별 허용 타입/라벨 별칭을 검수.
3. 원본과 HTML의 좌표·문구·선 및 제외 영역을 대조한 검토 기록 작성.
4. 독립 검토 후에만 `gold_approved:true`로 변경. 평가 모델이 만든 결과를 자동으로 gold로 승격하지 않음.
5. 가족/개정본/노이즈 파생본은 동일 split에 배정하여 유출을 방지.

추가 수집은 기관과 서식 종류를 늘리고, 작성된 합성 예시와 스캔·촬영 변형을 각각 별도 태그로 구성합니다.
합성 열화는 실제 스캔으로 표기하지 않습니다. 사람이 읽을 수 있는 수준인지 확인한 후 포함합니다.
