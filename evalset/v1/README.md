# 평가 세트 v1 — 문서 이미지와 기준 HTML 꾸러미 9쌍

모델이 문서 이미지를 **수정 가능한 HTML 템플릿 꾸러미**로 잘 바꾸는지 재는 세트. 난이도마다 3쌍.

```
<id>/
  image.png|jpg     모델 입력
  reference/        기준 꾸러미 (template.html · schema.json · sample.json) — 이 이미지로 만들 수 있는 꾸러미의 한 예
  meta.json         난이도 · 입력 · 구조 · 출처 · 라이선스 · 기준 꾸러미의 점수
```

## 쓰는 법
```bash
python -m tplgen bench configs/local.json                 # 설정의 "images": "evalset/v1" → 모델 × 난이도 표 (runs/<out>/compare.md)
python -m tplgen bench configs/reference.json             # 길 검사: 기준 꾸러미를 답으로 → 9/9 이어야 정상
python -m tplgen check evalset/v1/irs_f8949/reference --image evalset/v1/irs_f8949/image.png
```
점수는 정답 꾸러미와 비교하지 않는다 (꾸러미를 돌려 보고 원본 이미지와 견준다). `reference/` 는 길 검사, 사람이 보고 비교할 본보기, 나중에 schema 를 비교하는 점수를 만들 때 쓴다.

## 한계
- **기준 꾸러미는 사람이 아니라 큰 모델(Claude)이 이미지를 보고 쓰고 셀프 고치기로 다듬은 것이다. 사람이 검수하지 않았다.** 값으로 뺄지 고정 글자로 둘지(예: 인보이스의 공급자 이름) 같은 판단은 한 가지 예일 뿐이다.
- 9쌍뿐이다. 난이도별 통과율의 차이가 1장(33%p)씩 움직인다.
- 실제 스캐너로 뜬 문서, 여러 쪽 문서, 관공서 한국어 공문이 없다. `hf153_scan` 은 깨끗한 그림을 스캔처럼 만든 것이다 (`tools/scanify.py`).
- 하나은행 서식 그림은 공개 서식 PDF 에 가짜 값을 채워 그린 것이고, 영수증 사진은 올린 쪽이 익명화했다고 밝힌 공개 데이터다. 실서류는 넣지 않는다.
